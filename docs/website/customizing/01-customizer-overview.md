# Customizer overview

**Included in Free**

Go to **Appearance > Customize**. KnowX has its own Customizer built in, so no plugin is needed. Changes preview live and apply when you publish.

| Section | What it controls | Page |
|---|---|---|
| Site Skin | Colour scheme and theme colour | [Colour schemes and dark mode](02-colour-schemes-and-dark-mode.md) |
| Color Mode | Default light, dark or automatic mode and the visitor toggle | [Colour schemes and dark mode](02-colour-schemes-and-dark-mode.md) |
| Site Title, Headings, Menu, Body | Fonts, sizes and colours of text | [Typography](03-typography.md) |
| Site Layout, Site Blog, Site Sidebar, Site Loader, Scroll Top | Page width, blog and archive layout, sidebars | [Layout, sidebar and blog](04-layout-sidebar-and-blog.md) |
| Site Header, Site Sub Header | Sticky header, backgrounds, breadcrumbs and search bar | [Header and sub header](05-header-and-sub-header.md) |
| Footer Section, Copyright Section | Footer background and text, copyright line | [Footer and copyright](06-footer-and-copyright.md) |
| Knowledge Base Layout One, Layout Two | Docs home hero and support block, Docs Index options | [Docs home settings](07-docs-home-settings.md) |

WordPress' own panels still apply: **Site Identity** (logo, title, tagline, icon), **Homepage Settings**, **Menus**, **Widgets** and **Additional CSS**. The theme does not repeat them.

## Defaults

Every setting has a default, so a new site looks right without opening the Customizer. If you clear a field, the default returns.
