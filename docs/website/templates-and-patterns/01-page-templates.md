# Page templates

**Included in Free**

Choose a template in the **Page** box of the page editor.

| Template | Use it for |
|---|---|
| Docs Home | The front page of your docs: hero search, product cards, featured and recent articles, support block. |
| Docs Index | One page that lists every category with its latest articles. |
| FAQ | A single narrow column for questions. See [FAQ and changelog](../features/03-faq-and-changelog.md). |
| Changelog | A single narrow column with a divider above each release heading. |
| Page Without Sidebar | A normal page in the site container with no sidebar. |
| Full Width, No Title | A page with no container and no visible title, for page builders. A page heading is kept for screen readers unless your content has its own. |

Pages without a template use the default page layout with the sidebar setting.

## Templates WordPress picks for you

| Content | Template |
|---|---|
| A top-level category (product) | Sections with their first articles |
| A child category (section) | Paged list of articles with excerpts |
| A post in a product | Docs article: section tree, article, contents |
| A post outside any product | Standard post layout |
| Search | Results list, with an empty state and a search form |
| Not found | A message and a search form |
