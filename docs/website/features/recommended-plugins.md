# Recommended Plugins

KnowX suggests three optional plugins through the TGM Plugin Activation library. After you activate the theme, WordPress shows a prompt in the admin to install them. All three are optional; the theme functions without them.

## The recommendations

| Plugin | Slug | Required | Why |
|--------|------|----------|-----|
| Kirki Toolkit | `kirki` | No (recommended) | Powers every KnowX Customizer panel. Install this to unlock the General, Typography, Knowledge Base, WP Login, and Site Footer options. |
| Collapsing Categories | `collapsing-categories` | No | Build expandable, collapsible category lists, handy for a knowledge base sidebar. |
| WordPress Popular Posts | `wordpress-popular-posts` | No | Surface your most-viewed articles. |

## Installing them

1. After activating KnowX, look for the admin notice prompting recommended plugins, or go to **Appearance > Install Plugins**.
2. Select the plugins you want, then use the bulk **Install** and **Activate** actions.

## Important: Kirki Toolkit

Kirki is technically optional, but without it the KnowX-specific Customizer panels do not appear. If your Customizer is missing the KnowX options (General, Typography, Knowledge Base, WP Login, Site Footer), install and activate **Kirki Toolkit** first.

## Plugins detected automatically

You do not install these through KnowX, but the theme adapts when they are already active:

- **bbPress** - adds bbPress sidebars and a forum breadcrumb rule.
- **Elementor** - registers Elementor theme locations so Elementor can control the header and footer.
- **Jetpack** - loads a Jetpack integration component.
