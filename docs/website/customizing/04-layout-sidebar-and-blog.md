# Layout, sidebar and blog

**Included in Free**

## Layout

- **Site Layout**: wide or boxed.
- **Max Content Layout Width**: the width of the content container. The default is 1170px.

## Sidebar

**Sidebar** is left, right, both or none. It applies to the blog, archives, search and ordinary pages. Articles that belong to a product use the docs layout, which has its own section tree instead of a sidebar. **Sticky sidebar** keeps the sidebar in view while the page scrolls.

Fill the sidebars under **Appearance > Widgets** (Right Sidebar and Left Sidebar). A sidebar with no widgets shows nothing.

## Posts Page

- **Blog Layout**: list, grid or masonry-style columns.
- **Post Per Row**: one to four columns for the grid layouts.
- **Post Box View Layout**: show each post as a box.

## Site Loader and Scroll Top

- **Site Loader**: a small animation while the page loads. Off by default.
- **Scroll Top**: a back-to-top button after scrolling. Off by default.
