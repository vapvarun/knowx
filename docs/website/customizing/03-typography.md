# Typography

**Included in Free**

Go to **Appearance > Customize > Typography**. Each group opens from its title; Body Text is open first.

| Group | Applies to |
|---|---|
| Body Text | Paragraphs and all other text |
| Headings (H1 to H6) | All headings in articles and pages |
| Menu | The main navigation |
| Site Title and Tagline | The name and the line under it in the header |

Each group sets the font family, size, weight, line height, letter spacing, text transform and colour.

## Fonts

KnowX ships one font, **Open Sans**, served from your own site, so visitors' browsers make no request to Google. The font list shows the fonts the theme declares in `theme.json` and any font you add through the WordPress **Font Library** in the Site Editor.

The defaults are tuned for reading documentation: body text 16px with a 1.7 line height, bold headings, a 26px site title and a 15px menu. If you leave the family empty, the theme uses Open Sans with the system fonts as a fallback.

## Colours

Text colours in these groups override the colours the theme derives. Leave them empty to keep readable colours in both light and dark mode.
