# FAQ and changelog pages

## FAQ

1. Create a page and choose the **FAQ** template.
2. Insert the **Frequently asked questions** pattern (category **KnowX Docs**), or add core **Details** blocks yourself. The summary is the question and the content inside is the answer.

Pages with two or more Details blocks also print FAQ structured data, built from the same visible questions and answers. See [Structured data](04-structured-data.md).

## Changelog

1. Create a page and choose the **Changelog** template.
2. Add one heading per release, newest first. The **Changelog entry** pattern gives you a heading and a list of New, Improve and Fix lines.

## Patterns

The theme registers a **KnowX Docs** pattern category with: Frequently asked questions, Getting started steps, Note callout, Changelog entry and Contact support.
