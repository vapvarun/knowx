# Layout and sidebar

**Included in Free**

## Layout

- **Site Layout**: wide or boxed.
- **Max Content Layout Width**: the width of the content container. The default is 1170px.
- **Corners**: Square, Soft (default) or Round. It sets the corner radius of cards, buttons, inputs and blocks together, so the whole site changes shape from one choice.

## Sidebar

**Sidebar** is left, right, both or none. It applies to the posts page and ordinary pages. Articles that belong to a product use the docs layout, which has its own section tree instead of a sidebar. **Sticky sidebar** keeps the sidebar in view while the page scrolls.

Fill the sidebars under **Appearance > Widgets** (Right Sidebar and Left Sidebar). A sidebar with no widgets shows nothing.

## Scroll Top

- **Scroll Top**: a back-to-top button after scrolling. Off by default.

KnowX has no page loader: an animation that covers the page only delays what readers came for.
