# Colour schemes and dark mode

Go to **Appearance > Customize > Site Skin**.

## Colour scheme

Pick one of six schemes: Cool, Minimal, Monochrome, Pastel, Vibrant or Warm. A scheme sets the page and card colours, the text colour and the theme colour. Choose **Default** for the standard look.

A scheme is a file in the theme's `styles` folder (a theme.json style variation), so a child theme can add more.

## Theme colour

The theme colour is used for buttons, links and highlights. Link and button text colours are chosen automatically so they stay readable. A colour you set here wins over the scheme. A product's accent colour wins over both on that product's pages.

## Dark mode

Under **Site Skin** choose the default mode: light, dark or follow the visitor's device. The header toggle lets visitors change it, and their choice is remembered in their browser.
