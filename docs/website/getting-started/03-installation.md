# Installation

**Included in Free**

## From WordPress

1. Go to **Appearance > Themes > Add New Theme**.
2. Search for **KnowX** and choose **Install**, then **Activate**.

## From a zip file

1. Download the zip.
2. Go to **Appearance > Themes > Add New Theme > Upload Theme**, choose the zip and install it.
3. Choose **Activate**.

## After activation

The theme creates nothing on its own. The Dashboard shows a **Set up your docs site** notice: add the [sample docs](05-sample-content.md) to see a finished site, create an empty docs home, or dismiss it and follow [First setup](04-first-setup.md) to add your first product.

**Appearance > KnowX** is the theme's getting started screen: the same setup buttons (until you have a docs home), a card for each thing you can do next with a link to its screen and its guide, and links to the guides and the support forum.

## Updating from KnowX 1.x

Version 2.0 no longer uses the Kirki plugin and has fewer colour options, because the other colours are derived from the theme colour. After updating, review **Appearance > Customize**; earlier Customizer choices are not carried over. You can deactivate and delete Kirki.
