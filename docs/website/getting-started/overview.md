# KnowX Overview

KnowX is a free WordPress theme built for knowledge bases, documentation sites, and help centers. It ships with two dedicated knowledge base page templates, a live Customizer for controlling layout, typography, colors, header, footer, and login styling, and a breadcrumb system so visitors can always find their way back.

## What KnowX gives you

- **Two knowledge base homepage templates** - "Knowledge Base Layout One" and "Knowledge Base Layout Two" arrange your post categories and articles into a browsable landing page.
- **A full Customizer control set** powered by the Kirki toolkit, grouped into General, Typography, Knowledge Base, WP Login, and Site Footer panels.
- **Header and footer control** - sticky header, optional sub-header with breadcrumbs and search, and four footer widget areas plus a copyright bar.
- **Built-in breadcrumbs** that integrate with Yoast SEO when it is present and fall back to KnowX's own breadcrumb trail otherwise.
- **Custom WordPress login styling** - replace the login logo, its link, and the login page title from the Customizer.
- **Classic sidebars and widgets**, including a KnowX Categories widget and bbPress-specific sidebars.
- **Block editor support** - a color palette, font sizes, wide alignment, block styles, and a footer block pattern.

## Who it is for

KnowX suits teams that want a self-hosted knowledge base without a page builder dependency. It works with the standard WordPress editor and Customizer, and it recognizes bbPress, Elementor, and Jetpack when those plugins are active.

## How KnowX is built

KnowX is a classic (PHP template) theme scaffolded on [WP Rig](https://github.com/wprig/wprig). It uses the traditional template hierarchy (`header.php`, `footer.php`, `index.php`, `single.php`, page templates) rather than the block-based Full Site Editing model. It also ships a small `theme.json` file to define the block editor palette, font sizes, and layout widths.
