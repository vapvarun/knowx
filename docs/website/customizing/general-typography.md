# General and Typography

These options live in the **General** and **Typography** panels of the Customizer (**Appearance > Customize**). The Kirki Toolkit plugin must be active.

## General panel

### Site Layout

- **Site Layout** - choose the overall layout. The default is **wide**. Your choice adds a `layout-<value>` class to the `body` element, so themes and custom CSS can target it.
- **Max Content Layout Width** - set the maximum content width for the site.

### Site Loader

- **Site Loader?** - enable an animated page loader that shows while the page loads. The default value is `2`. The animated dot loader displays when the value is set to `1`.
- **Site Loader Background** - the background color shown behind the loader.

### Scroll Top

- **Scroll Top** - enable a scroll-to-top button. When enabled, KnowX enqueues its ScrollUp script on the front end.

## Typography panel

KnowX uses the Kirki typography controls, which let you pick font family, weight, size, line height, letter spacing, and color for each area.

### Site Title

- **Site Title Settings** - typography for the site title.
- **Site Title Hover Color** - color when hovering the site title link.

### Site Tagline

- **Site Tagline Settings** - typography for the site tagline.

### Headings

Independent typography controls for each heading level:

- **H1 Tag Settings**
- **H2 Tag Settings**
- **H3 Tag Settings**
- **H4 Tag Settings**
- **H5 Tag Settings**
- **H6 Tag Settings**

### Menu

- **Menu Settings** - typography for the primary navigation menu.
- **Menu Hover Color** - link color on hover.
- **Menu Active Color** - color of the active or current menu item.

### Body

- **Body Settings** - typography for the main body content.

## Local Google Fonts

If you use Google Fonts through the typography controls, you can host them locally for privacy and performance. Open **Site Footer > Site Performance**:

- **Load Google Fonts Locally?** - download and serve Google Fonts from your own server instead of Google's CDN.
- **Preload Local Fonts?** - add preload hints for the local font files.
- **Flush Local Fonts Cache** - clear the cached local font files if fonts change or become stale.
