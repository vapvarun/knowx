# Installation

**Included in Free**

## From WordPress

1. Go to **Appearance > Themes > Add New Theme**.
2. Search for **KnowX** and choose **Install**, then **Activate**.

## From a zip file

1. Download the zip.
2. Go to **Appearance > Themes > Add New Theme > Upload Theme**, choose the zip and install it.
3. Choose **Activate**.

## After activation

The theme creates nothing on its own. Follow [First setup](04-first-setup.md) to add your first product, or load the [sample content](05-sample-content.md) on a test site.

## Updating from KnowX 1.x

Version 2.0 no longer uses the Kirki plugin and has fewer colour options, because the other colours are derived from the theme colour. After updating, review **Appearance > Customize**; earlier Customizer choices are not carried over. You can deactivate and delete Kirki.
