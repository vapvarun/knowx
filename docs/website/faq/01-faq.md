# Frequently asked questions

**Included in Free**

## Do I need a plugin?

No. KnowX uses categories, posts, pages and core blocks.

## How many products can I have?

As many as you like. The docs home lists up to 100 products and the Products menu lists the same ones.

## Can I use one product only?

Yes. With one product the header Products menu is hidden and the docs home shows a single card.

## Why does my product not appear on the home page?

A product appears when its category has no parent and has at least one published article, directly or in a section. Check that the category is not listed in **Exclude category by ID**, and that it is not the default "Uncategorized" category on a site with other products.

## How do I order articles?

Use the **Order** field in the editor sidebar. Articles with the same order are sorted by title.

## How do I show an article's version?

Fill in **Docs > Applies to version** in the editor sidebar.

## Does it support dark mode?

Yes. Set the default under **Site Skin** and let visitors switch with the header toggle.

## Does it work with page builders?

Use the **Full Width, No Title** template for builder pages. The theme loads no builder-specific code.

## Is it translation ready and right-to-left ready?

Yes. The text domain is `knowx`, and the layout uses logical CSS properties, so right-to-left languages mirror.

## What happened to Kirki and the old colour options?

Version 2.0 builds its own Customizer and derives most colours from the theme colour. See [Installation](../getting-started/03-installation.md).
