# Customizer Overview

KnowX adds its theme options to the WordPress Customizer (**Appearance > Customize**). These options are built with the Kirki Toolkit, so you must have the **Kirki Toolkit** plugin active for the KnowX panels to appear. Every change previews live before you publish.

## Panels and sections

KnowX organizes its options into the following panels. Each panel contains one or more sections.

### General

- **Site Layout** - overall site width (wide or boxed) and max content width.
- **Site Loader** - enable a page loading animation and set its background.
- **Scroll Top** - enable a scroll-to-top button.
- **Site Header** - sticky header toggle and header background color.
- **Site Sub Header** - toggle the sub-header, its background, content typography, breadcrumbs, and search.
- **Site Skin** - body background, theme color, link colors, and button colors.
- **Site Blog** - blog layout, posts per row, and post box view.
- **Site Sidebar** - sidebar position, bbPress sidebar position, and sticky sidebar.

### Typography

- **Site Title** - site title font, size, and hover color.
- **Headings** - typography for H1 through H6.
- **Menu** - menu font, hover color, and active color.
- **Body** - body content typography.

### Knowledge Base

- **Knowledge Base Layout One** - hero section, support (call-to-action) section, and category display options for the Layout One template.
- **Knowledge Base Layout Two** - category display options for the Layout Two template.

### WP Login

- **Logo** - custom login logo, login logo link, and login page title. See [Custom Login](../features/custom-login.md).

### Site Footer

- **Footer Section** - footer background, colors, and links.
- **Copyright Section** - copyright text and colors.
- **Site Performance** - load Google Fonts locally, preload local fonts, and flush the local font cache.

## Standard WordPress sections

KnowX also works with the standard Customizer sections:

- **Site Identity** - logo, title, tagline (KnowX supports a logo up to 250x250 px, flexible).
- **Menus** - assign a menu to the Primary location.
- **Widgets** - manage the sidebar and footer widget areas.
- **Homepage Settings** - choose your static front page.
- **Background Image** and **Header** - KnowX declares `custom-background` and `custom-header` support.
- **Theme Options** - a small extra section KnowX registers before Additional CSS.
