# Header and Footer

Control the site header, sub-header, footer widgets, and copyright bar from the Customizer (**Appearance > Customize**). The Kirki Toolkit plugin must be active for these options.

## Site Header

Found in **General > Site Header**:

- **Enable Sticky Header?** - keep the header fixed at the top of the screen as visitors scroll. Enabled by default. When on, KnowX adds a `sticky-header` class to the `body`.
- **Header Background Color** - the background color of the header bar.

The header displays your logo and site title (the branding area) and the Primary navigation menu. If Elementor is active and you have built an Elementor header for the `header` location, KnowX renders that instead.

## Site Sub Header

Found in **General > Site Sub Header**. The sub-header is a secondary bar shown below the main header on inner pages (it is hidden on the front page).

- **Site Sub Header?** - show or hide the sub-header. Enabled by default.
- **Customize Background?** and **Background Control** - set the sub-header background.
- **Content Typography** - typography for sub-header text.
- **Site Breadcrumbs?** - show breadcrumbs inside the sub-header. Enabled by default. See [Breadcrumbs](../features/breadcrumbs.md).
- **Site Search?** - show a search field inside the sub-header. Enabled by default.

## Footer widgets

KnowX registers four footer widget areas: **Footer 1**, **Footer 2**, **Footer 3**, and **Footer 4**. Add widgets under **Appearance > Widgets** or **Customize > Widgets**. Only the footer areas that contain widgets are rendered, and they lay out side by side in the footer.

If Elementor is active and you have built an Elementor footer for the `footer` location, KnowX renders that instead of the widget footer.

## Footer Section

Found in **Site Footer > Footer Section**:

- **Customize Background?** and **Background Control** - footer background.
- **Title Color** - color of widget titles in the footer.
- **Content Color** - footer body text color.
- **Link Color** and **Link Hover** - footer link colors.

## Copyright Section

Found in **Site Footer > Copyright Section**:

- **Add Content** - the copyright text shown in the footer bar. You can use the placeholders `[current_year]` (replaced with the current year) and `[site_title]` (replaced with a link to your homepage using your site name).
- **Background Color** - copyright bar background.
- **Border Color** - top border of the copyright bar.
- **Content Color** - copyright text color.
- **Link Color** and **Link Hover Color** - copyright link colors.
