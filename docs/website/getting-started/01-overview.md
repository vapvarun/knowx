# KnowX overview

**Included in Free**

KnowX is a WordPress theme for documentation and FAQ sites. It works for one product or many, and it needs no plugin and no custom post type.

## What you get

- A docs home page with a card for each product, an icon and accent colour per product, and a Products menu in the header
- Article pages with a section tree, an "On this page" list, previous and next links and a version badge
- Instant search that can be limited to the current product
- FAQ and changelog page templates and a set of block patterns
- schema.org data and a meta description
- Light and dark mode and one theme colour
- A fast front end: no jQuery, no icon font, one self-hosted font and no external requests

## How a docs site is built

| You create | In WordPress |
|---|---|
| A product | A top-level category |
| A section of a product | A child category |
| An article | A post |
| An FAQ or changelog | A page with the FAQ or Changelog template |
