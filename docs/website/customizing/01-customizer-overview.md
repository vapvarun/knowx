# Customizer overview

**Included in Free**

Go to **Appearance > Customize**. KnowX has its own Customizer built in, so no plugin is needed. Changes preview live and apply when you publish.

| Section | What it controls | Page |
|---|---|---|
| Colors | Colour scheme, theme colour (with quick picks) and page background | [Colour schemes and dark mode](02-colour-schemes-and-dark-mode.md) |
| Dark Mode | Default light, dark or automatic mode and the visitor toggle | [Colour schemes and dark mode](02-colour-schemes-and-dark-mode.md) |
| Typography: Site Title, Headings, Menu, Body | Fonts, sizes and colours of text | [Typography](03-typography.md) |
| Header, Breadcrumb Bar | Sticky header, backgrounds, breadcrumbs and search box | [Header and breadcrumb bar](05-header-and-sub-header.md) |
| General: Layout, Site Loader, Scroll Top | Page width, loading animation, back-to-top button | [Layout, sidebar and posts page](04-layout-sidebar-and-blog.md) |
| Docs: Docs Home, Articles, Docs Index | Docs home hero and lists, what an article shows, the Docs Index template | [Docs home settings](07-docs-home-settings.md) |
| Sidebar, Posts Page | Sidebar position, and the layout of the posts page | [Layout, sidebar and posts page](04-layout-sidebar-and-blog.md) |
| Site Footer: Footer Section, Copyright Section | Footer background and text, copyright line | [Footer and copyright](06-footer-and-copyright.md) |

WordPress' own panels still apply: **Site Identity** (logo, title, tagline, icon), **Homepage Settings**, **Menus**, **Widgets** and **Additional CSS**. The theme does not repeat them.

## Defaults

Every setting has a default, so a new site looks right without opening the Customizer. If you clear a field, the default returns.
