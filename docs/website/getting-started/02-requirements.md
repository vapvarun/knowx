# Requirements

**Included in Free**

| Requirement | Minimum |
|---|---|
| WordPress | 6.9 (tested up to 7.1) |
| PHP | 8.1 |
| Browser | Current Chrome, Edge, Firefox and Safari (Safari 16.4 and later, iOS 16.4 and later) |

No plugin is required. Pretty permalinks are recommended, for example **Post name**, under **Settings > Permalinks**.

## Optional

- An SEO plugin. KnowX stops printing its own meta description when Yoast SEO, Rank Math, All in One SEO, SEOPress or The SEO Framework is active.
- A persistent object cache. It is not needed: the theme caches its own lists.
