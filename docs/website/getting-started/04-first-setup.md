# First setup

**Included in Free**

This takes about ten minutes.

On a new site the theme has already created a **Knowledge Base** page with the Docs Home template and set it as your homepage, and it shows a panel that links to the next step.

## 1. Add a product

1. Go to **Posts > Categories**.
2. Add a category with no parent, for example "Acme App".
3. Write a short description. It appears on the product card.
4. Choose an **icon**. To give the product its own colour, tick **Use an accent colour** and pick one.

## 2. Add sections

Add child categories under the product, such as "Getting started" and "Guides". Sections can nest one level deeper.

## 3. Write articles

Add posts and tick one section for each. Use the **Order** field in the editor sidebar to put articles in order. If an article applies to one version of your product, fill in **Docs > Applies to version**.

## 4. Create the home page

1. Go to **Pages > Add New**, title it "Documentation" and choose the **Docs Home** template. The excerpt is shown under the title.
2. Go to **Settings > Reading**, choose **A static page** and pick that page as the homepage.

## 5. Add the menu

Go to **Appearance > Menus**, create a menu with your pages (for example Docs, FAQ, Changelog) and assign it to the **Primary** location. The **Products** menu is added automatically when you have two or more products.

## 6. Make it yours

Open **Appearance > Customize**. Start with **Colors** for the theme colour and page background, and **Site Identity** for the logo. See the [Customizer overview](../customizing/01-customizer-overview.md).
